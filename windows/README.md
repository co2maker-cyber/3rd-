# 윈도우 서버 실습장

네트워크관리사 2급 실기의 Windows Server 2016 설정 문제를 브라우저에서 연습하는 시뮬레이터입니다. 실제 서버 관리 도구처럼 생긴 창에서 직접 설정하고, 오른쪽 패널에서 채점합니다.

- 실행 파일: `windows/index.html` (브라우저로 열면 바로 동작, 설치 필요 없음)
- 과제는 21개이며 [새 문제]를 누를 때마다 IP 주소, 도메인, 이름 같은 값이 새로 정해집니다.
- 완료 표시는 브라우저에만 저장됩니다.
- 실제 Windows의 화면과 동작을 단순화해 흉내 낸 연습용입니다.

## 조작법

| 동작 | 방법 |
|---|---|
| 도구 열기 | 바탕 화면 아이콘, 시작 단추, 서버 관리자 → 도구(T) |
| 실행 창(Win+R) | 시작 단추 **오른쪽 클릭** → 실행(R) |
| 상황에 맞는 메뉴 | 항목 오른쪽 클릭, 창의 **동작(A)** 메뉴, 터치 화면은 길게 누르기 |
| 속성 열기 | 항목 두 번 클릭 |
| IP 주소 입력 | 숫자 3자리나 `.`을 치면 다음 칸으로 넘어갑니다. |
| 채점 | 설정을 마친 뒤 패널의 [채점하기] |

대부분의 설정은 실제 Windows처럼 **마지막 창의 [확인]** 까지 눌러야 저장됩니다. 예를 들어 TCP/IPv4 속성에서 확인을 눌러도 바깥쪽 `Ethernet0 속성` 창에서 확인을 누르지 않으면 적용되지 않습니다.

## 실행(Win+R) 명령어

| 명령 | 여는 도구 |
|---|---|
| `ncpa.cpl` | 네트워크 연결 |
| `dnsmgmt.msc` | DNS 관리자 |
| `dhcpmgmt.msc` | DHCP |
| `inetmgr` | IIS(인터넷 정보 서비스) 관리자 |
| `dsa.msc` | Active Directory 사용자 및 컴퓨터 |
| `secpol.msc` | 로컬 보안 정책 |
| `wf.msc` | 고급 보안이 포함된 Windows 방화벽 |
| `sysdm.cpl` | 시스템 속성 (컴퓨터 이름, 원격 데스크톱) |
| `cmd` | 명령 프롬프트 |
| `explorer` | 파일 탐색기 |
| `servermanager` | 서버 관리자 |

## 과제 목록

| 분류 | 과제 | 주요 내용 |
|---|---|---|
| 네트워크 설정 | TCP/IPv4 고정 IP 설정 | IP, 서브넷 마스크(접두사 환산), 게이트웨이, DNS |
| | 고급 TCP/IP · IPv6 해제 | 두 번째 IP, 보조 DNS, DNS 접미사, NetBIOS 사용 안 함, IPv6 해제 |
| DNS | 정방향 조회 영역 만들기 | 주 영역, AD 저장 해제, 영역 파일 이름, 동적 업데이트 |
| | 호스트·별칭·메일 교환기 레코드 | A, CNAME, MX(우선 순위) |
| | 역방향 조회 영역과 PTR 레코드 | 네트워크 ID, 연결된 PTR 레코드 만들기 |
| | SOA · 영역 전송 · 동적 업데이트 | 새로 고침/다시 시도/만료/최소 TTL, 다음 서버로만 전송 |
| | 전달자와 조건부 전달자 | 전달자 순서, 루트 힌트, 조건부 전달자 |
| DHCP | DHCP 범위 만들기 | 범위 이름, 주소 범위, 길이/마스크, 제외, 임대 기간, 003/006/015 옵션, 활성화 |
| | 예약 · 제외 · 범위 옵션 | 예약(MAC), 제외 범위, 옵션 수정, 범위 속성 |
| IIS | 웹 사이트 추가 | 실제 경로, 바인딩(IP·포트·호스트 이름), 바인딩 충돌과 사이트 중지 |
| | 기본 문서 · 디렉터리 검색 · 연결 제한 | 기본 문서 추가·순서·제거, 디렉터리 검색, 제한 |
| | IP 주소 제한과 인증 | 허용/거부 항목, 지정되지 않은 클라이언트 거부, 익명/기본 인증 |
| | FTP 사이트 추가 | 바인딩, SSL, 인증, 권한 부여(읽기/쓰기) |
| Active Directory | 조직 구성 단위와 사용자 만들기 | OU, 사용자, 암호 정책 검사, 계정 옵션 |
| | 그룹 만들기와 구성원 추가 | 그룹 범위·종류, 구성원, 사용자 속성 |
| 보안 정책 | 암호 정책과 계정 잠금 정책 | 암호 길이·사용 기간·기록·복잡성, 잠금 임계값과 제안 값, 감사 정책 |
| 파일 공유 | 폴더 공유와 공유 권한 | 고급 공유, 숨김 공유($), 동시 사용자 수, 공유 권한 |
| | NTFS 보안 권한 | 사용자 추가, 수정 허용, 쓰기 거부, 상속 권한 |
| 방화벽 | 인바운드 규칙 만들기 | 포트 규칙, 작업, 프로필, ICMPv4 에코 요청 허용 |
| 시스템 | 원격 데스크톱 허용과 컴퓨터 이름 | 원격 연결, NLA, 원격 데스크톱 사용자, 컴퓨터 이름 변경 |
| 명령 프롬프트 | 네트워크 명령어 | `ipconfig /all · /flushdns · /displaydns · /registerdns`, `netstat -an`, `route print`, `arp -a`, `ping -n`, `tracert`, `nslookup`, `net share` |

## 서버 기본 상태

| 항목 | 값 |
|---|---|
| 컴퓨터 이름 | `SERVER` (도메인 컨트롤러) |
| 도메인 | `netlab.local` |
| Ethernet0 | `192.168.100.10/24`, 게이트웨이 `192.168.100.1`, DNS `127.0.0.1` |
| 설치된 역할 | AD DS, DNS, DHCP, IIS(웹·FTP), 파일 서비스 |

과제를 고르거나 [처음부터]를 누르면 서버가 이 상태로 돌아간 뒤 과제에 필요한 준비(영역, 폴더, 사용자 등)가 더해집니다.
