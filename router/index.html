    PC에서 본 연결
    
      
    R1 설정에 따라 LAN의 PC들이 실제로 통신할 수 있는지 계속 확인합니다.
    
      
      
    
      

    
      
      
      토폴로지
      
      
      
      
      통신 가능켜졌지만 IP·캡슐화가 안 맞음꺼짐
      
      
      
        
      장비포트주소비고
      
        
          
      PC1NIC192.168.1.10/24게이트웨이 .1 · TFTP 서버
      
          
      PC2NIC192.168.1.20/24게이트웨이 .1
      
          
      PC3NICDHCP주소를 자동으로 받음
      
          
      R2S0/1/010.0.0.2/30HDLC · RIPv2 · OSPF 0 · EIGRP 100
      
          
      R2S0/1/02001:DB8:12::2/64IPv6
      
          
      R2Lo02.2.2.2/32라우터 ID
      
          
      R2G0/0172.16.0.1/242001:DB8:172::1/64
      
          
      SRVNIC172.16.0.102001:DB8:172::10
      
          
      ISPG0/0203.0.113.1/30DHCP로 .2 를 줄 수도 있음
      
          
      ISP—198.51.100.0/29R1에 할당된 공인 대역
      
          
      인터넷—8.8.8.8 · 1.1.1.1dns.google 로도 조회
      
              
      
      
    
      

    
      
      모드와 핵심 명령 정리
      
      PC 키보드 단축키 (IOS와 같음)
      
        
      Tab · ?
      자동완성 · 도움말 (입력창을 누르지 않아도 됨)
      
        
      ↑ ↓ · Ctrl+P
      이전 명령
      
        
      Ctrl+A · Ctrl+E
      줄 맨 앞 · 맨 끝으로
      
        
      Ctrl+B · Ctrl+F
      커서 한 칸 왼쪽 · 오른쪽
      
        
      Ctrl+U · Ctrl+K · Ctrl+D
      커서 앞 지우기 · 뒤 지우기 · 한 글자 지우기
      
        
      Ctrl+R · Ctrl+L
      입력 줄 다시 보기 · 화면 지우기
      
        
      Ctrl+Shift+6
      ping·traceroute·이름 조회 중단
      
        
      Ctrl+Z · Ctrl+C · Esc
      특권 모드로 · 입력 취소 · 줄 비우기
      
        
      Ctrl+Break · Pause
      부팅 중 ROMMON 진입
      
      
      
      
      모드 이동
      
        
      R1> → enable → R1#
      사용자 EXEC → 특권 EXEC
      
        
      configure terminal
      전역 설정 R1(config)#
      
        
      interface g0/0
      R1(config-if)# · range, 서브인터페이스 g0/0.10도 가능
      
        
      router ospf 1 / rip / eigrp 100
      R1(config-router)#
      
        
      line console 0 / vty 0 4
      R1(config-line)#
      
        
      ip dhcp pool LAN
      R1(dhcp-config)#
      
        
      ip access-list extended NAME
      R1(config-ext-nacl)#
      
        
      exit · end · Ctrl+Z
      한 단계 위로 · 특권 모드로 바로
      
      
      
      
      확인할 때
      
        
      show ip interface brief
      포트 IP와 up/down 요약
      
        
      show ip route
      C 연결 · S 정적 · R RIP · O OSPF · D EIGRP
      
        
      show running-config | section router
      파이프: include · exclude · begin · section · count
      
        
      show ip protocols
      동작 중인 라우팅 프로토콜
      
        
      show cdp neighbors
      포트마다 붙은 장비
      
        
      show interfaces s0/0/0
      캡슐화, 대역폭, 상태 자세히
      
        
      terminal length 0
      --More-- 없이 한 번에 출력
      
      
      
      
      저장과 복구
      
        
      copy running-config startup-config
      저장 (write memory, wr)
      
        
      copy running-config tftp:
      PC1(192.168.1.10) TFTP 서버로 백업
      
        
      reload · erase startup-config
      재부팅 · 저장된 설정 지우기
      
        
      Break → confreg 0x2142
      비밀번호 복구 (ROMMON)
      
      
      
      
      문제 찾기
      
        
      ping 172.16.0.1 source g0/0
      출발지 바꿔 ping · ping 만 치면 확장 ping
      
        
      traceroute 8.8.8.8
      경로 추적
      
        
      debug ip rip · undebug all
      디버그 켜고 끄기 (u all)
      
        
      show logging
      지금까지의 로그 메시지
