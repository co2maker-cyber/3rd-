      모드와 명령어 정리
      
    R1> 사용자 EXEC
    
        
    enable
    특권 모드로 들어가기
    
        
    ping 10.0.0.2
    연결 확인. ! 성공, . 시간 초과, U 도달 불가
    
        
    show ip interface brief
    인터페이스 IP와 up/down 요약
    
      
    
      
    R1# 특권 EXEC
    
        
    configure terminal
    전역 설정 모드로 (conf t)
    
        
    show running-config
    지금 동작 중인 설정 (sh run)
    
        
    show ip route
    라우팅 테이블. C 연결, S 정적, R RIP, O OSPF
    
        
    show cdp neighbors
    각 포트에 어떤 장비가 붙었는지
    
        
    copy running-config startup-config
    설정 저장 (wr 로 줄여도 됨)
    
        
    reload
    재부팅. 저장 안 한 설정은 사라짐
    
      
    
      
    R1(config)# 전역 설정
    
        
    hostname R1
    장비 이름
    
        
    enable secret class
    특권 모드 비밀번호 (암호화 저장)
    
        
    interface g0/0
    인터페이스 설정 모드로
    
        
    ip route 네트워크 마스크 다음홉
    정적 경로. 0.0.0.0 0.0.0.0 은 기본 경로
    
        
    router rip / router ospf 1
    동적 라우팅 설정 모드로
    
        
    line console 0 / line vty 0 4
    콘솔·원격 접속 라인 설정
    
        
    do show ip route
    설정 모드에서 show 명령 실행
    
      
    
      
    R1(config-if)# 인터페이스
    
        
    ip address 192.168.1.1 255.255.255.0
    IP 주소와 서브넷 마스크
    
        
    no shutdown
    포트 켜기. 라우터 포트는 기본이 꺼짐
    
        
    description LAN
    설명 달기
    
      
    
      
    R1(config-router)# 라우팅 프로토콜
    
        
    version 2 · no auto-summary
    RIPv2, 자동 요약 끄기
    
        
    network 10.0.0.0
    RIP: 클래스풀 네트워크 단위로 지정
    
        
    network 10.0.0.0 0.0.0.3 area 0
    OSPF: 와일드카드 마스크와 영역
    
        
    passive-interface g0/0
    그 포트로는 라우팅 업데이트를 보내지 않음
    
      
    
      
    공통
    
        
    exit · end · Ctrl+Z
    한 단계 나가기 · 특권 모드로 바로
    
        
    no 명령
    그 설정을 취소
    
        
    ?
    지금 칠 수 있는 명령 목록
