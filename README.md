## 네트워크관리사 2급 실습장

네트워크관리사 2급 실기 시험 범위를 직접 해 보고 자동으로 채점받는 연습 도구 세 가지입니다.

### 공통 사용법

- 화면 왼쪽이 실습 화면(콘솔·바탕 화면·터미널), 오른쪽이 과제 패널입니다.
- 과제 목록에서 과제를 고르면 요구 사항이 나옵니다. 설정을 마친 뒤 **[채점하기]**를 누릅니다.
- 틀린 항목에는 **기대 값**과 **현재 값**이 함께 나옵니다.
- **[풀이 보기]**는 지금 문제의 값에 맞춘 풀이 순서를 보여 줍니다.
- **[새 문제]**는 IP 주소, 이름, 포트 같은 값을 새로 정하고, **[처음부터]**는 같은 값으로 처음 상태로 돌립니다.
- 완료 표시는 그 브라우저에만 저장됩니다(localStorage). 서버로 보내는 데이터는 없습니다.
- 휴대폰 너비에서도 쓸 수 있습니다.

### 라우터 콘솔 연습장 (`router/`)

Cisco IOS 스타일 명령어를 콘솔에 직접 입력해 보는 시뮬레이터입니다. 실습 14개와 자유 연습이 있고, 명령어 415개를 지원합니다.

| 영역 | 실습 |
|---|---|
| 기본 | 처음 받은 라우터 잠그기, 포트에 IP 주고 켜기, 콘솔 편의·로그·이름 조회 |
| 라우팅 | 정적·기본 경로, RIPv2, 단일 영역 OSPF, EIGRP AS 100, IPv6 주소와 정적 경로 |
| 서비스·보안 | R1을 DHCP 서버로, PAT로 인터넷 내보내기, 확장 ACL, SSH 원격 접속 |
| 문제 해결 | 고장 난 라우터 고치기, enable 비밀번호 복구(ROMMON) |

조작: `Tab` 자동 완성, `?` 도움말, `↑ ↓` 이전 명령, `Ctrl+Z` 특권 모드로, 부팅 중 `Break`로 ROMMON 진입.

### 윈도우 서버 실습장 (`windows/`)

Windows Server 2016의 관리 도구 화면을 흉내 낸 GUI 시뮬레이터입니다. 과제 21개와 자유 연습이 있습니다.

| 분류 | 과제 |
|---|---|
| 네트워크 설정 | TCP/IPv4 고정 IP, 고급 TCP/IP · IPv6 해제 |
| DNS | 정방향 영역, A·CNAME·MX 레코드, 역방향 영역·PTR, SOA·영역 전송, 전달자·조건부 전달자 |
| DHCP | 범위 만들기(권한 부여 포함), 예약·제외·범위 옵션 |
| IIS | 웹 사이트 추가, 기본 문서·디렉터리 검색·연결 제한, IP 제한·인증, FTP 사이트 |
| Active Directory | OU와 사용자, 그룹과 구성원 |
| 보안 정책 | 암호·계정 잠금·감사 정책 (로컬 보안 정책, 그룹 정책 관리) |
| 파일 공유 | 공유와 공유 권한, NTFS 권한 |
| 방화벽 · 시스템 | 인바운드 규칙, 원격 데스크톱·컴퓨터 이름 |
| 명령 프롬프트 | `ipconfig`, `netstat`, `route`, `nslookup` 등 |

도구는 바탕 화면, 시작 메뉴, 서버 관리자 → 도구, 시작 단추 오른쪽 클릭 → 실행(`ncpa.cpl`, `dnsmgmt.msc`, `dhcpmgmt.msc`, `inetmgr`, `dsa.msc`, `secpol.msc`, `gpmc.msc`, `wf.msc`, `sysdm.cpl`, `cmd`)으로 엽니다. 실제 Windows처럼 바깥쪽 창의 [확인]까지 눌러야 설정이 저장됩니다.

### 리눅스 서버 실습장 (`linux/`)

CentOS 7 서버에 SSH로 접속한 터미널을 흉내 낸 시뮬레이터입니다. 과제 21개와 자유 연습이 있습니다.

| 분류 | 과제 |
|---|---|
| 파일 관리 | 파일·디렉터리, chmod(SetUID·스티키 비트 포함), chown·chgrp, umask, 하드·심볼릭 링크 |
| 사용자 관리 | 사용자·그룹 만들기, usermod·chage·잠금·삭제, 그룹 관리 |
| 네트워크 | ifcfg·nmcli 고정 IP, 호스트 이름·hosts·resolv.conf |
| 서비스 | systemctl·firewalld, SSH 서버 설정, httpd 설정 |
| 패키지 · 프로세스 · 백업 | yum·rpm, kill·renice, tar·gzip |
| 디스크 · 예약 | mkfs·mount·fstab, cron |
| 명령어 · 편집기 | 시스템 정보 확인, find·grep·cut·awk, vi 편집기 |

- 파이프(`|`), 리디렉션(`> >> 2>`), `&&`, 와일드카드, `Tab` 자동 완성을 지원합니다.
- `vi`는 일반·입력·명령 모드, `dd` `yy` `p` `u` `/찾기` `:%s/a/b/g` `:set nu` `:wq`를 지원합니다.
- `reboot`하면 영구 설정(ifcfg, fstab, `systemctl enable`, `firewall-cmd --permanent`)만 남으므로 임시 설정과 영구 설정의 차이를 확인할 수 있습니다.
- `help`로 명령어 목록, `man 명령`으로 옵션 요약을 봅니다.

### 테스트

- 헤드리스 Chromium(Playwright)에서 윈도우 21개, 리눅스 21개 과제를 실제 화면 조작과 명령 입력으로 풀어 모두 만점을 확인했습니다.
- 윈도우는 모든 도구의 메뉴·대화 상자·마법사를 자동으로 순회해 스크립트 오류가 없음을 확인했습니다.
- 리눅스는 잘못된 입력을 포함한 명령 300여 개를 실행해 내부 오류가 없음을 확인했습니다.
- 데스크톱과 휴대폰(iPhone 13 에뮬레이션) 화면을 확인했습니다.

### 실제 장비와 다른 점

세 실습장 모두 실제 장비·OS의 동작을 단순화한 연습용입니다. 화면 문구와 메뉴 위치, 명령 출력은 실제와 조금 다를 수 있고, 시험에 잘 나오지 않는 기능은 빠져 있습니다. 자세한 차이는 각 안내서의 마지막 절에 정리되어 있습니다.

## 배포

정적 파일뿐이라 GitHub Pages 같은 정적 호스팅에 그대로 올리면 됩니다. 폴더 링크(`router/` 등)는 웹 서버에서 각 폴더의 `index.html`로 열립니다. 파일을 컴퓨터에서 직접 열 때는 `router/index.html`처럼 파일을 지정해 여세요.
