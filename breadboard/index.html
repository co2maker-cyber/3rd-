    저장 · 불러오기

    이 기기에 저장

    지금 쓰는 브라우저 안에 이름을 붙여 저장해요. 인터넷이 없어도 되고, 같은 기기·같은 브라우저에서 다시 불러올 수 있어요.

    파일로 저장 · 불러오기

    회로를 파일(.json)로 내려받아 보관하거나 다른 기기로 옮길 수 있어요. 내려받은 파일을 다시 골라 불러와요.

    부품 고르기
    종류를 눌러 들어가고, ‹ 로 한 단계 나와요. 부품을 누르면 창이 닫히고 보드에서 놓을 자리를 누르면 꽂혀요(두 번 누르면 빈자리에 바로).
    파일로 부품 배치
    회로도 사진(PNG·JPG) 또는 부품·연결 목록(TXT·CSV·JSON)을 여기로 끌어다 놓으세요

    본인이 만들었거나 사용 허락을 받은 회로도·자료만 올려 주세요(유료 교재·시험지·남의 비공개 도면은 올리지 마세요). 올린 사진과 글은 보드에 배치할 부품·연결을 읽어내는 데에만 쓰여요. 목록 파일은 이 브라우저 안에서만 처리하고, 사진이나 자유 형식 글은 읽기 위해 Claude에 전달돼요.

    파일을 올리거나 아래 칸에 목록을 직접 쓰세요. 배치하기 전에 읽은 내용을 확인하고 고칠 수 있어요.
    목록 쓰는 법

    한 줄에 부품 하나 또는 연결 하나를 써요. #로 시작하는 줄은 메모예요.

    # 부품: 이름  종류  [값]
U1  74LS08            ← IC 이름 (74LS·74HC·CD4511·NE555 등)
R1  저항  330         ← 220 · 330 · 1k · 4.7k · 10k · 47k · 100k · 1M
D1  LED  red          ← red · green · yellow · blue
SW1 스위치 on          ← on 이면 켜진 채로 시작
BTN1 버튼 · C1 커패시터 47u · CLK1 클럭 1 · DS1 7세그 anode
G1  AND               ← 단독 게이트 (AND OR NOT NAND NOR XOR XNOR)

# 연결: [이름:] 핀, 핀, 핀 ...
VCC: U1.14            ← VCC/GND는 + / − 레일로 이어져요
N1: U1.3, R1.1        ← IC는 핀 번호(데이터시트 기준)
N2: R1.2 - D1.A       ← LED는 A(+) / K(−), 2단자 부품은 1 / 2
GND: D1.K

    IC의 전원 핀(VCC·GND)을 빠뜨리면 자동으로 레일에 이어요. CSV는 ref,type,value 형식의 부품 줄도 읽어요.
