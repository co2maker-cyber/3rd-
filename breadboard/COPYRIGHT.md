# 저작권 및 지식재산권 준수 안내 (Copyright & IP Compliance)

본 문서는 `breadboard/` 브레드보드 CAD 시뮬레이터의 개발·배포·유지보수 과정에서 저작권법, 반도체집적회로의 배치설계에 관한 법률, 상표법 등 관련 법령을 준수하기 위한 기준과 사용자 고지 사항을 정리한 문서입니다.

## 1. 프로젝트 코드 및 시뮬레이션 모델의 권리 범위

* **자체 제작 소스코드:** `breadboard/index.html` 내 논리 시뮬레이션 엔진, RC 아날로그 근사 풀이, UI/렌더링 코드, 기본 예제 회로(`EXAMPLES`)는 교육 및 실험 목적을 위해 자체 설계·구현되었습니다.
* **기능적 사양과 표현의 분리:** 74HC/74LS 시리즈, CD4511, NE555 등 범용 집적회로(IC)의 핀 번호, 입출력 논리 테이블, 기본 동작 특성은 호환성과 표준 규격에 기반한 **기능적·사실적 정보**를 바탕으로 구현되었으며, 특정 반도체 제조사의 공식 데이터시트 도면·문구·레이아웃을 그대로 복제하지 않습니다.
* **반도체 배치설계권 비침해:** 본 시뮬레이터는 핀 단위의 논리적·전기적 동작만을 모사하며, 실제 IC칩 내부의 트랜지스터·배선 배치설계(Mask Work)나 상용 펌웨어·마이크로코드를 추출·복제·배포하지 않습니다.

## 2. 상표 및 표준 형번 표기 원칙

* 본 프로젝트에서 사용하는 `74LS00`, `74HC00`, `NE555`, `CD4511` 등의 명칭은 전자공학 및 교육 현장에서 통용되는 범용 부품 번호(Generic Part Numbers)를 지칭합니다.
* 각 반도체 제조사가 보유한 등록 상표 및 로고는 해당 권리자에게 귀속되며, 본 프로젝트는 특정 제조사의 공식 제품이거나 제휴·보증된 소프트웨어가 아닙니다.
* 향후 신규 부품(`CHIPS`, `GATES`)을 추가할 때는 특정 기업의 고유 브랜드명이나 상표를 제품명처럼 사용하지 않고, 표준 기능명 또는 범용 형번 위주로 표기합니다.

## 3. 외부 리소스 및 오픈소스 라이선스 관리

* **웹 폰트(Google Fonts):** `breadboard/index.html`에서 불러오는 외부 폰트는 각 폰트 배포처가 지정한 오픈소스 라이선스(예: SIL Open Font License 등) 조건 범위 내에서 사용합니다. 배포 시 해당 폰트의 라이선스 조건(단독 폰트 파일 재판매 금지 등)을 준수합니다.
* **외부 코드·예제 유입 통제:** 타인의 코드 스니펫, SVG 아이콘, 회로 예제, 문서 문구를 반영할 경우 반드시 출처와 라이선스(MIT, Apache 2.0, CC BY 등)를 확인하고, 라이선스 고지 의무가 있는 경우 본 문서 또는 `LICENSE` 파일에 명시합니다.

## 4. 사용자 업로드 자료(회로도 이미지·텍스트 파일) 처리 기준

시뮬레이터의 **회로도 사진 읽기(`askClaude`)** 및 **부품 목록 불러오기(`openImport`)** 기능 이용 시 아래 기준을 적용합니다.

1. **이용자 권리 확인:** 사용자는 본인이 저작권을 보유했거나, 저작권자의 허락을 받은 회로도·문서·학습 자료만을 업로드해야 합니다. 유료 교재, 시험 문제지, 타인의 비공개 설계 도면을 무단으로 복제·배포하는 용도로 사용할 수 없습니다.
2. **목적 외 이용 금지:** 사용자가 입력한 회로도 이미지 및 부품 텍스트 데이터는 브레드보드 배선 변환 및 시뮬레이션 실행 목적에만 사용되며, 권리자 동의 없이 외부에 공개·재배포하지 않습니다.

## 5. 개발·유지보수 체크리스트 (PR / 커밋 전 확인)

새 기능이나 부품을 추가할 때 아래 항목을 점검합니다.

* [ ] **핀 배치도(`pinoutSVG`):** 특정 제조사 데이터시트의 이미지·SVG를 복사하지 않고 자체 도식화 코드로 작성했는가?
* [ ] **설명 문구 및 툴팁:** 데이터시트나 온라인 강좌의 설명 문장을 그대로 복사·붙여넣기 하지 않았는가?
* [ ] **예제 회로(`EXAMPLES`):** 상용 교재나 타인의 저작물에 수록된 고유 회로를 출처·허락 없이 그대로 옮기지 않았는가?
* [ ] **서드파티 에셋:** 외부 아이콘, 폰트, 스크립트를 추가했다면 라이선스 표기 의무를 이행했는가?
